Маркетплейс торговли электроэнергией
Где: крупная энергетическая компания, работаю там backend / fullstack-разработчиком с мая 2026.
Проект: Django-монолит на 14+ приложений: розница и опт, генерация потребителя, аукцион поставщиков, паспорт сделки, ЭДО по 63-ФЗ. Задачи веду целиком сама: разбираю требования, расписываю кейсы, пишу код и открываю pull request.
Что сделала:
  • Аукцион поставщиков, главный модуль системы: календарь сроков, срез объёма, частичные заявки с лимитом. Пока идёт подписание, рынок заморожен; у поставщика торги обновляются вживую, а итоги видны в дашбордах и покупателя, и поставщика.
  • ЭДО по 63-ФЗ: документы подписываются электронной подписью, в печатных формах стоят отметки о подписании, компания регистрируется по машиночитаемой доверенности (МЧД), подпись проверяется.
  • Перестроила доменную модель прямо на живой системе: поменяла связи между сущностями и перенесла данные без потерь, а миграции сначала прогнала на копии прода.
  • Тесты: e2e-сценарии на Playwright, unit-тесты на pytest и пайплайны, которые их гоняют.
  • Ускорила запросы и главную страницу. Собрала локальный Docker-стек и образ для деплоя в k3s, перенесла медиафайлы в S3 так, чтобы можно было откатиться, подключила Redis Sentinel, чтобы Redis переживал падение узла.
  • Ревьюю ветки коллег, пишу бизнес-правила, документацию по workflow, RFC и issues.
С нейросетью: Claude Code у меня в работе каждый день. С ним планирую задачи, гоняю многоагентное ревью, генерирую тесты и документацию; инструкции для агентов лежат прямо в репозитории. Сейчас перевожу процесс на Spec-Driven Development через OpenSpec.
